# Closet

An AI personal stylist. Photograph a garment and it understands the item, building a style graph of your wardrobe that learns your taste over time.

## Concept

- Photograph garments to catalogue them
- A style graph, not a flat list
- Learns your preferences over time
- Weather-aware outfit suggestions
- Calendar and camera-overlay helpers

## Targets

- iOS
- ClosetMac
- ClosetWatch

## Stack

- SwiftUI
- SwiftData
- Apple Intelligence
- XcodeGen (`project.yml`)

## Structure

Key types: `AppleIntelligenceService`, `CalendarService`, `CameraOverlayGuide`, `CategoryChip`, `ClosetEmptyIllustration`.

Version 1.0.0.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.

Xcode projects here were generated with XcodeGen (`project.yml`); open the `.xcodeproj` directly.
